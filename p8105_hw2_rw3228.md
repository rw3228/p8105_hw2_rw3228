## Problem 1

``` r
transit_df = 
  read_csv(
    "data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv",
    na = c("", "NA")
  ) |>
  janitor::clean_names() |>
  select(
    line,
    station_name,
    station_latitude,
    station_longitude,
    starts_with("route"),
    entry,
    vending,
    entrance_type,
    ada
  ) |>
  mutate(
    entry = case_match(
      entry,
      "YES" ~ TRUE,
      "NO" ~ FALSE
    )
  )
```

The NYC Transit dataset contains information about subway station
entrances and exits in New York City, including the subway line and
station name, station latitude and longitude, routes served by each
station, whether entrance is allowed, vending availability, entrance
type, and ADA compliance.I used read_csv() to read the local CSV;
janitor::clean_names() to make the variable names easier to work with;
select() to keep only the variables requested by the assignment;
starts_with(“route”) to keep all the route variables; mutate(entry =
case_match(entry, “YES” ~ TRUE, “NO” ~ FALSE)) to change entry from a
character variable to a logical variable. The resulting dataset contains
1868 rows and 19 columns. The data are not tidy yet because the routes
served by each station are spread across multiple columns rather than
being stored in a single route variable.

The combined Trash Wheel dataset contains 1224 observations and 15
variables. Each observation represents a dumpster collection from one of
the three Trash Wheels: Mr. Trash Wheel, Professor Trash Wheel, or
Gwynnda. Key variables include the Trash Wheel name, dumpster number,
month, year, weight of trash in tons, volume of trash, and counts of
various types of trash such as plastic bottles and cigarette butts.
