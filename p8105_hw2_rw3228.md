``` r
transit_df =

      "YES" ~ TRUE,
      "NO" ~ FALSE
    )
  )
```

The NYC Transit dataset contains information about subway station
entrances and exits in New York City, including the subway line and
station name, station latitude and longitude, routes served by each
station, whether entrance is allowed, vending availability, entrance
type, and ADA compliance.I used read_csv() to read the local CSV;
janitor::clean_names() to make the variable names easier to work with;
select() to keep only the variables requested by the assignment;
starts_with(“route”) to keep all the route variables; mutate(entry =
case_match(entry, “YES” ~ TRUE, “NO” ~ FALSE)) to change entry from a
character variable to a logical variable. The resulting dataset contains
1868 rows and 19 columns. The data are not tidy yet because the routes
served by each station are spread across multiple columns rather than
being stored in a single route variable.

``` r
baseline_df =
```

The baseline demographic dataset was imported by skipping the first row,
which contained descriptive information rather than variable names, and
treating `.` as a missing value. Variable names were cleaned, and sex
and APOE4 carrier status were converted from numeric codes to
categorical variables. Participants who had MCI at baseline were
excluded to satisfy the study inclusion criteria. After cleaning, the
baseline dataset contains 479 participants. Of these participants, 93
developed MCI during follow-up. The average baseline age was 65.03
years. Among women, 30% were APOE4 carriers.

The longitudinal amyloid dataset was also imported by skipping the
descriptive first row and treating `.` as missing. After cleaning the
variable names, the data were converted from wide to long format so that
each row represents one amyloid 42/40 ratio measurement for one
participant at one time point. The tidy amyloid dataset contains 2435
observations and 3 variables, including participant ID, measurement
time, and amyloid ratio.

Comparison of participant IDs showed that 8 participants appeared only
in the cleaned baseline dataset, while 16 participants appeared only in
the amyloid dataset. An inner join was used to retain only participants
represented in both datasets. The resulting combined dataset contains
471 unique participants, 2355 observations, and 8 variables. Each
participant contributes longitudinal amyloid measurements along with
their baseline demographic and MCI information.
